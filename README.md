# 决策蒸馏 · Decision Distiller v4.0

把「我是怎么想的」变成可检验的系统：记录 → 复盘 → 蒸馏原则 → 校准训练。
单文件、零依赖、数据 100% 存在你自己设备上。

## 二、三种运行方式（任选）

### 方式 1：最简单——双击
直接双击 `index.html` 用浏览器打开。**全部功能可用**，只是没有"安装成 App"和"离线缓存"。

### 方式 2：本地服务器（推荐，可安装成 App）
在文件夹里打开终端，任选一个你电脑里有的：

```
python -m http.server 8080
# 或
npx serve .
```

然后浏览器访问 `http://localhost:8080`。

### 方式 3：手机上用（同一 Wi-Fi 下）
1. 电脑上按方式 2 启动服务器（注意绑定 0.0.0.0：`python -m http.server 8080 --bind 0.0.0.0`）
2. 手机浏览器访问 `http://<电脑的局域网IP>:8080`
3. 添加到主屏幕（见下）

## 三、安装成 App（PWA）

- **电脑 Chrome / Edge**：地址栏右侧出现"安装"图标，或点页面右上角「📲 安装App」
- **安卓 Chrome**：菜单 →「安装应用」
- **iPhone / iPad**：Safari「分享」→「添加到主屏幕」

安装后：独立窗口、主屏图标、断网可用，体验和原生 App 一致。

## 四、数据在哪？会丢吗？（v4.0：三道保险）

- 数据 100% 存在本机（localStorage + IndexedDB 双份），不上传任何服务器
- **保险 ①**：装到主屏/桌面成 PWA——已安装应用不受浏览器"7 天未访问清存储"策略影响
- **保险 ②**：IndexedDB 实时镜像——主存储被浏览器清掉时，下次打开自动找回
- **保险 ③**（Chrome/Edge 桌面）：设置页「数据保险」→ 选择自动备份文件，此后每 10 分钟静默落盘一次
- 手动导出的 JSON 备份**不含 API Key**，可放心同步/转移
- ⚠️ 未安装 PWA 的 iOS Safari 站点 7 天不访问会被清存储——iPhone 用户务必"添加到主屏幕"

## 七、三条量化线（首页看板）

只有文字的原则必然空泛。这三条是可验证的指标，每条都标着样本量：

| 指标线 | 怎么算 | 数据从哪来 | 怎么用 |
|---|---|---|---|
| **判断准确度** | Brier 分数（0=完美，0.25≈抛硬币） | 训练场 → 预测训练 | 每天记 1 条概率判断，30 天出曲线 |
| **过程质量** | 决策质量六要素，取**最弱环节** | 记录页 → 30 秒质量自检 | **要在下决定之前做**才有意义 |
| **原则执行力** | 1 − 原则违背率 | 复盘时勾选「遵守 / 违背」 | 违背率 >50% 的原则，系统会标为「愿望，不是原则」 |

### 为什么冷启动不再需要 1~2 年
真实决策一年 30 条，反馈周期以周/月计。系统用**双轨燃料**解决：

- **慢轨**（你自己的决策）→ 出原则、出证据链，慢但才是真数据
- **快轨**（训练场：15 题测评 + 每日预测 + 12 张情境卡）→ 30 天内就能拿到第一张可信的校准曲线和决策画像

**两轨数据分开统计，永不混合**。快轨只练概率手感，不能当作提炼原则的证据。

## 八、使用纪律（比功能更重要）

1. 前 20~30 条只记录，不蒸馏原则
2. 同类情境出现 3 次以上再提炼 if-then 原则
3. 决策质量 ≠ 结果质量——复盘时过程分和结果分分开打，系统只优化过程分
4. 质量自检在**事前**做：事后打分只是自我评分，事前自检才能拦住烂决定
5. 复盘时诚实勾「违背」——系统不需要好看的数据，需要真的数据

## 九、理论依据索引

| 功能 | 依据 |
|---|---|
| AI 对话第一问是情绪 | 情绪标注效应，Lieberman et al., 2007（fMRI） |
| 原则用 if-then 格式 | 执行意图，Gollwitzer, 1999 |
| 可证伪承诺必填 | 波普尔证伪主义；防事后合理化 |

| 测评五维度 | CRT（Frederick 2005）、A-DMC（Bruine de Bruin 2007）、框架效应（Tversky & Kahneman 1981） |

## 十、v4.0 更新说明（2026-10-24，接手后第一次迭代）

### 数据安全（先于一切功能）
- **修复：Skill"脱敏导出"此前是假的**（两个版本内容相同）——现在脱敏版真正剔除原则"依据"原文，并如实标注内容范围
- **修复：备份文件泄露 API Key**——导出统一剥离密钥，导入时保留本机已配置的
- **新增：三道数据保险**（见第四节）+ 旧版本数据自动迁移补全字段

### 补齐核心闭环
- **复盘日历（.ics）**：首页/详情页/设置页可导出复盘提醒到手机/电脑日历——**App 不开着也会到点提醒**（PWA 做不了系统推送，这是可靠路径）。重复导入会产生重复事件，新增决策后重新导出即可
- **决策时原则推送**：快捕/引导向导里输入情境时，实时匹配你的原则（文本相似度+领域+证据链），附该领域的过程分战绩——"可信度加权"从仪表盘变成事前干预

### 科学性修复
- **框架效应计分**：原版只把"两次都选确定项"算免疫（把风险偏好当成了错误）。现按 Tversky & Kahneman 原设计：两次同构问题选择一致（无论稳健还是冒险）= 框架免疫 100 分
- **未答题不再默认选 A**：此前选择题不答会被静默计为第一项
- **校准分公式**改为 Brier 口径（平方误差）
- **校准桶对称变换**：习惯给低概率（"30% 会发生"）的预测不再整条曲线隐身——等价于对反面下 70% 注
- **闪卡升级为真间隔重复**（Leitner 五盒：1/3/7/16/35 天），答错回盒 1 并当场重排队；训练场显示"待复习 N 张"
- **情境卡选项随机打乱**——修掉"10/12 题答案在第三项"的可刷题漏洞
- **测评加信度声明**：每维度仅 1~5 题，结果按"方向参考"使用；保留历史，重测看变化量
- 首页 Brier 卡片明确标注**代理轨**（预测训练数据），与真实决策校准分开——贯彻"两轨永不混合"

### 新功能（借 awesome-ai-persona-skills 生态的思路，行为版）
- **🌱 种子原则库**（原则库页）：预装达利欧/芒格/塔勒布等 10 条经典 if-then 原则，安装后与自建原则进入**同一套违背率检验**——长期违背的种子说明不适合你，删掉即校准
- **🩺 AI 会诊升级**：配置 AI 后，芒格/塔勒布/纳瓦尔/反方的追问**针对这条决策现场生成**（引用你的选项、预期、可证伪承诺），不再是固定问题库；AI 不可用自动退回固定题库
- **🧱 决策考古**（记录页第 4 入口）：粘贴过去的日记/聊天记录，AI 提取"结果已知"的历史决策回溯建档——**第三条轨：考古轨**。考古记录诚实标注：不进校准曲线、不进过程分（没有事前承诺的不算证据），但进模式统计与原则证据链
